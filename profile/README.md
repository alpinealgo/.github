# AlpineAlgo

**L'IA promet. Je vérifie.**

Je viens de Suisse romande, et je teste l'IA sur de vraies tâches de finance et de tous les jours : backtests, tableaux de bord, consignes, robots qui tournent la nuit. Ce qui marche, ce qui casse, avec les chiffres. Ici, vous trouvez les outils qui sortent de ces tests, prêts à reprendre.

## À télécharger

- **[Le compteur de tirets longs](https://github.com/alpinealgo/compteur-de-tirets)** : fini les textes qui sonnent IA. Il compte les tirets longs et les mots en capitales dans vos documents finis.
- **[La relecture de nuit](https://github.com/alpinealgo/relecture-de-nuit)** : Claude relit vos notes Obsidian pendant que vous dormez, et vous laisse deux résumés le matin.
- **[Mes consignes en une page](https://github.com/alpinealgo/consignes-en-une-page)** : le fichier que Claude lit à chaque session, tenu sur une page.

Chaque outil a son article, qui raconte comment il est né et ce qui a planté en route.
